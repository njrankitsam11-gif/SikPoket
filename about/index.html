About Sik

Sik is a small, remote studio that builds local-first tools for people who live in tabs. Our first two products are SikPoket — the encrypted bookmark vault on this domain — and SikOgami (sikogami.vercel.app) — a paper-folding companion that teaches origami offline. Both share the same design system: Paper #FDFBF7, Ink #0A0A0A, Sick #FF3B30, brutalist 2px borders and hard shadows. No design trend, just paper and ink.

Sik was started in 2025 by a researcher who kept losing links across Notion, Raindrop and browser bookmarks. The goal was simple: a vault that never sends your data to a server, works offline on a plane, and still feels calm. SikPoket stores everything in chrome.storage.local or localStorage. Your master password never leaves RAM; it derives an AES-GCM 256 key via PBKDF2 (100,000 rounds) inside the Web Crypto API. We have no way to read it, even if we wanted to.

Auth & encryption

Two ways to unlock: a master password (in-memory only, wiped on lock) or a WebAuthn platform credential (Touch ID / Face ID / Windows Hello). The same key encrypts URLs, notes, API keys and passwords before they are written to disk. Want cross-device? The only network call SikPoket ever makes is an optional, client-encrypted GitHub Gist sync — you bring your own PAT, we encrypt before upload. See crypto-helper.js and sync-helper.js on GitHub.

SikPoket is also a lab for offline intelligence. Search is TF-IDF in search-helper.js — tokenizes titles, tags and notes, scores exact vs. partial matches, and sorts without a server. Summaries use Chrome’s on-device Gemini Nano via window.ai with a TextRank fallback, so a 5,000-word article becomes three bullets without leaving the browser. Even the ambient focus sounds (Rain, Brown noise, 432Hz) are synthesized with the Web Audio API — no MP3s.
