Local-first • Zero-knowledge • Open

SikPoket is your encrypted bookmark vault for research that never leaves your device.

Save URLs, notes, API keys and passwords with client-side AES-GCM 256 encryption (PBKDF2 100k). Organize them in wallpaper Spaces, find them instantly with offline TF-IDF search, and share them via offline QR — no tracking servers, no accounts required. Built by Sik for researchers, developers and creators who want a calm, paper-like workspace that works offline and syncs only if you want it to. The Chrome side panel (Ctrl+Shift+E) keeps your vault docked beside any tab; drag-and-drop tabs, highlights and links straight into your vault. Procedural Web Audio soundscapes, reader mode, and Netscape HTML export keep you focused and portable.

🔒 Zero-Knowledge Encryption

Master password derives an in-memory AES-GCM 256 key via PBKDF2. Ciphertext only touches chrome.storage.local. WebAuthn Touch ID / Face ID unlock optional.

No eval • 0 tracking • 100% local

Developer resources — Vercel & SikPoket

SikPoket is deployed on Vercel — the same platform that powers vercel.json routing, proxy.js middleware, and serverless functions at /api/mcp and /api/health. All resources below are hosted on Vercel at sikpoket.vercel.app.

  • Vercel deployment — https://sikpoket.vercel.app on Vercel, vercel.json with Vary: Accept, proxy.js for Accept: text/markdown. See Vercel developers portal
  • SikPoket API — Vercel serverless — local helpers: crypto-helper.js (AES-GCM), search-helper.js (TF-IDF), qr-helper.js (QR), export-helper.js (Netscape/JSON) — see llms.txt and /developers on Vercel
  • OpenAPI 3.1 — Vercel — /openapi.json versioned at /api/v1/mcp with API-Version header, Deprecation/Sunset, and RateLimit headers — hosted on Vercel
  • Auth — Vercel — master password (PBKDF2) or WebAuthn platform credential — docs at /about#auth and /developers
  • Webhooks — Vercel — none (local-first); optional GitHub Gist encrypted sync via sync-helper.js — Vercel serverless
  • MCP server — Vercel @vercel/mcp-adapter — Streamable HTTP at /.well-known/mcp (live handshake) and POST /api/mcp and POST /api/v1/mcp — Vercel Streamable HTTP
  • Health — Vercel — /api/health and /api/v1/health — JSON with RateLimit-Limit and Vary: Accept on Vercel
