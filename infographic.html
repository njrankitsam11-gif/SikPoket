05 // Cryptographic Model

Zero-Knowledge Security Specifications

🔑 PBKDF2 Key Derivation
Master passwords derive an in-memory AES-256 CryptoKey using SHA-256 with 100,000 iterations and a unique 16-byte cryptographic salt.
🛡️ AES-256-GCM Cipher
Authenticated hardware encryption with a randomized 12-byte initialization vector (IV) per save. Plaintext never touches disk.
👆 WebAuthn Biometrics
Touch ID / Face ID hardware authenticators provide local biometric unlock without storing passwords on disk.
