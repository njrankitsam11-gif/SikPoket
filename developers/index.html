Developer portal — SikPoket for agents

Build with SikPoket — local-first vault for agents.

SikPoket is a zero-knowledge, local-first bookmark manager. All vault data lives in chrome.storage.local with client-side AES-GCM 256 (PBKDF2 100k) and optional WebAuthn. The hosted surface is intentionally tiny: discovery files, a health check, and a Streamable HTTP MCP server so agents can call search_vault, save_url, list_spaces and export_bookmarks without ever seeing plaintext. Deploy on Vercel — the same platform that hosts this site.

View OpenAPI → MCP handshake GitHub

Quickstart (30s)

curl https://sikpoket.vercel.app/.well-known/mcp
curl https://sikpoket.vercel.app/openapi.json
curl -X POST https://sikpoket.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Vercel: fork the repo, vercel --prod. No env vars required. Local vault helpers live at crypto-helper.js, search-helper.js, qr-helper.js.

API keys & auth

No hosted API keys — SikPoket is local-first. Master password derives an in-memory AES-GCM key via PBKDF2. Optional WebAuthn platform credential (Touch ID / Face ID). No remote sync of any kind — your vault never leaves your device. Docs: /about#auth.

MCP server — Streamable HTTP

Endpoint https://sikpoket.vercel.app/.well-known/mcp (GET handshake, POST JSON-RPC) and POST https://sikpoket.vercel.app/api/mcp. Transport streamable-http, version 2025-06-18. Tools: search_vault (TF-IDF), save_url, list_spaces, export_bookmarks. Try in sandbox below.

POST /api/mcp
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {"name": "search_vault", "arguments": {"query": "react"}}
}

OpenAPI & discoverability

Full spec at /openapi.json and /api/openapi.yaml (if you prefer YAML). Also listed in llms.txt and sitemap.xml. Every operation has a unique operationId, typed parameters, and response schemas for LLM function calling.

Webhooks & Vercel

No webhooks — local-first, no remote sync of any kind. Hosted on Vercel with vercel.json routing, proxy.js for Accept: text/markdown negotiation, and Vary: Accept.
